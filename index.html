This website

avivashishta.com is a React 19 + TypeScript single-page app built with Vite and deployed on Vercel. It uses Three.js and React Three Fiber for 3D, GSAP for scroll animation, and MediaPipe for real-time hand-gesture and head-tracking controls — you can navigate the site without touching your mouse. Press Ctrl + J for an interactive terminal with 27 commands and built-in AI chat.
