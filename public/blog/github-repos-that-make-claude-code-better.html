1. obra/superpowers ~290K ★

github.com/obra/superpowers

A skills framework and a development methodology in one. It gets the agent to plan before it writes, write the test first, and review its own work before it tells you it is done. That last part is the one that matters — the default failure mode of every coding agent is declaring victory on code it never ran.

Start here. It is the highest-leverage install on the list.

2. affaan-m/ECC ~266K ★

github.com/affaan-m/ECC

A harness optimization system: memory, instincts, security rails and research-first development bolted onto Claude Code, Codex, Opencode and Cursor. Where superpowers gives the agent a method, ECC gives it an environment — the things you would otherwise rebuild by hand in every repo.

3. mksglu/context-mode ~24K ★

github.com/mksglu/context-mode

Sandboxes large tool output — logs, test runs, diffs — so it does not spend your context window. This is the least glamorous repo here and the one you notice fastest. A single failing test suite can dump tens of thousands of tokens of stack traces into a session; three of those and your agent has forgotten what you asked for. Trimming the output at the tool boundary is what keeps long sessions useful.

It works through MCP plus hooks, so it applies across agents rather than inside one.

4. max-sixty/worktrunk ~8K ★

github.com/max-sixty/worktrunk

A CLI for git worktree management, built for parallel agent workflows. Give each agent its own branch and its own folder, and run several at once without them trampling each other's edits or colliding on merge.

Running more than one agent in a single checkout is the mistake everyone makes once. Worktrees are the boring, correct fix, and this wraps the ceremony.

5. stablyai/orca ~76K ★

github.com/stablyai/orca

An agent development environment for running a fleet of agents in parallel — desktop, mobile and a remote runtime, using your own subscription and whichever coding agent you prefer. Pairs naturally with worktrunk: worktrunk isolates the filesystem, orca gives you somewhere to watch all of it at once.

6. akitaonrails/ai-memory ~8K ★

github.com/akitaonrails/ai-memory

Long-term memory for agent CLIs, explicitly designed for handoff between vendors. Everything you taught Claude Code about your codebase carries over when you open the same project in Codex or Cursor instead of starting from zero.

7. DietrichGebert/ponytail ~145K ★

github.com/DietrichGebert/ponytail

Rules that steer the agent toward the simplest thing that works. The project describes it as making your agent think like the laziest senior dev in the room, which is exactly right: the best code is the code you never wrote.

Left alone, agents reach for abstraction — a factory where a function would do, a config layer for a value that changes once a year. This is the counterweight.

8. ayghri/i-have-adhd ~51K ★

github.com/ayghri/i-have-adhd

A skill that stops the agent burying the answer. Answer first, filler cut. Small, and it changes every single response you read for the rest of the day.

My setup — how they fit together

These are not eight separate installs so much as four layers. This is the order I would add them in:

  1. superpowers — how the agent works. Plan, test, self-review.
  2. worktrunk + orca — three to five agents running in parallel, each in its own worktree.
  3. context-mode — so those long parallel sessions do not drown in their own tool output.
  4. ai-memory — so switching tools does not reset what the agent knows about the project.

ECC overlaps with a few of these and is worth taking as a whole rather than piecemeal. Ponytail and i-have-adhd are rule files — add them last, once the rest is working, and judge them on whether the output reads better.

The pattern worth noticing

Not one of these repos makes the model smarter. They fix the harness around it: what the agent can remember, how much of the window it wastes, whether two of them can run without colliding, and whether it checks its own work before claiming it is finished. That is where the 10x is — the model has been good enough for a while; the scaffolding around it is what has been thin.
