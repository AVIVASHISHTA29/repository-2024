How I'd use this

  • Pick 3, not 30. One RAG app, one agent, one MCP project. That covers most AI app developer interviews.
  • Don't just clone and run. Change the data source to something you care about, like your college notes or a docs site you use daily, give it a live URL and write a real README.
  • Put the "what I changed" part at the top of your README. That's the part a founder reads.
  • Post the build in public while you make it. A day 1 ugly demo beats a day 30 perfect demo nobody saw.
  • Use Claude Code or Codex to read the code with you, but make sure you can explain every file in an interview.
