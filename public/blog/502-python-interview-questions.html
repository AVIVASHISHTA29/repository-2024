They come from three GitHub repos, and every link jumps straight to its answer. I removed the questions one repo repeats, so the count is unique questions.

The short version: Python rounds test three things: how well you know the language (Part 1), whether you can write it (Part 2), and whether you understand what it actually does (Part 3). Start with the 4 topics below, then build the 3 small things after.

The 4 I'd start with

  1. Data types and mutability. Data types, core data structures and mutable vs immutable. Start with is a tuple mutable or immutable?
  2. Functions, *args and **kwargs. Functions, lambdas and *args and **kwargs.
  3. Iterators, generators and decorators. Iterators and generators, decorators and context managers. This is where Python rounds separate juniors from seniors.
  4. The "what's the output?" snippets. All 64 in Part 3. Read the snippet, guess the output, then read why.

What to build to prove you get it

  1. A decorator that times any function and logs slow calls.
  2. A generator that reads a huge log file line by line without loading it into memory.
  3. A context manager that opens a database connection and always closes it.

You don't need all 502. You need to explain generators and decorators while writing one live.
