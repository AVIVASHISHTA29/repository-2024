446 React Interview Questions to Crack Frontend Placements

Published October 2026 · avivashishta.com

You commented react, so here are all 446 questions. They come from sudheerj/reactjs-interview-questions, and every one has a full written answer with code in the repo. Each link below jumps straight to its answer. I pulled the list from the repo's README on 1 October 2026.

The short version: 354 current questions plus 92 legacy ones, sorted by topic. Do Hooks and Modern React first, answer each question out loud, then build one small project that uses what you just read. That project is what you talk about in the interview.

Heads up: 92 of the 446 sit in the repo's "Old Q&A" section. Those are older class-component and legacy-API questions the author keeps separate. They still come up in some interviews and in old codebases, but start with the current ones. 80 of the questions (mostly in Old Q&A) don't get their own anchor on GitHub, so those links open the README and you'll need Ctrl + F.

A long-running list of React interview questions with written answers and code examples, kept up to date with React 18 and 19. MIT licensed and free.

The 4 sections I'd start with

  1. Hooks (55 questions). useState, useEffect, useRef, useMemo, useCallback, useReducer and custom hooks. Most frontend rounds live here.
  2. Modern React Features, React 18/19 (37). Concurrent rendering, Server Components, Server Actions, the use hook, useOptimistic. This is what separates you from people who learned React in 2021.
  3. Core React (77). JSX, virtual DOM, reconciliation, props vs state, keys. The fundamentals every round starts with.
  4. React Router (11). Protected routes, 404 pages, query params, loaders and actions.

What to build after

A small app with a protected route, one custom hook, a form using Actions and one optimistic update. Deploy it with a live link.
