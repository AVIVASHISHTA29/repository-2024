518 JavaScript Interview Questions to Crack Placements in 2027

Published October 2026 · avivashishta.com

You commented js, so here are all 518 questions. They come from sudheerj/javascript-interview-questions, and every one has a full written answer, most with code, in the repo. Each link below jumps straight to its answer. I pulled the list from the repo's README on 2 October 2026 and sorted the questions by topic myself, so a few could fit in more than one group.

The short version: 518 questions in 11 topics, plus 87 "what's the output?" coding exercises at the end of the repo. Master closures, promises and the event loop first, do the coding exercises, then build the 3 small things below. That's what you talk about in the interview.

The repo

A long-running list of JavaScript interview questions with written answers and code, from the same author as the React interview questions repo. Free to read on GitHub.

The 4 I'd start with

  1. Closures and hoisting. What are closures, What is hoisting and the Temporal Dead Zone. The first thing every JS round tests.
  2. Promises and async/await. 50 questions in the async section, starting with What is a promise.
  3. The event loop. What is the event loop and tasks in the event loop. If you can draw it, you can answer half the async questions.
  4. The 87 coding exercises. "What's the output?" questions at the end of the repo. The most common JS round in Indian frontend interviews.

What to build to prove you get it

  1. Your own debounce function, then use it on a search box.
  2. Your own version of bind, using call or apply.
  3. A fetch wrapper that retries failed requests with promises.

You don't need all 518. You need to explain closures without saying "it's when a function remembers".
